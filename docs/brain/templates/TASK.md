# Active task template

Use this structure when replacing the current `ACTIVE-TASK.md` for an authorized
new task; preserve the previous task in a handoff first. Follow the
[memory protocol](../MEMORY-PROTOCOL.md).

- **Task identifier and title:** retain existing Roadmap IDs when applicable.
- **Date:** YYYY-MM-DD.
- **Status:** in progress until verification supports a later status.
- **Objective:** concrete outcome.
- **Scope:** permitted files and behavior.
- **Restrictions:** Git, runtime, data, provider and publication boundaries.
- **Starting Git baseline:** repository identity, branch, SHA, tracked/untracked
  changes and unresolved operations; stash metadata if required by the task.

## Acceptance criteria

Observable deliverables and scoped checks; distinguish planned from executed.

## Progress and unresolved issues

What is done, what remains, relevant decisions and missing evidence.

## Handoff

Link the actual handoff and verification evidence when available.
